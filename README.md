# Kimberley26

An [Obsidian](https://obsidian.md) notebook to track the journey, geological notes and observations of the **August 2026 geological exploration of the coast north of Perth, Australia**.

---

## About

This vault documents a coastal geological survey travelling north from Perth along the Western Australian coastline. It captures:

- 📅 **Daily journal entries** — travel, weather, field conditions and highlights
- 🪨 **Geological observations** — rock descriptions, structural measurements and interpretations
- 📍 **Location profiles** — notes on each site visited along the route
- 📦 **Rock sample catalogue** — inventory of collected specimens

## Vault Structure

```
Kimberley26/
├── Home.md                  # Start here — expedition overview and navigation
├── Journal/                 # Day-by-day field notes
├── Geology/                 # Geological observations and sample log
├── Locations/               # Site profiles (Lancelin, Cervantes, Jurien Bay, Kalbarri…)
├── Templates/               # Note templates (journal, observation, location, sample)
└── Resources/               # Reference material, maps and equipment checklist
```

## Getting Started

1. Install [Obsidian](https://obsidian.md/download) (free).
2. Open this folder as a vault in Obsidian: **Open folder as vault**.
3. Start at [[Home]] for the expedition overview.
4. Use `Ctrl+Shift+D` to create today's journal entry.

## Route

Perth → Lancelin → Cervantes (Pinnacles) → Jurien Bay → Green Head → Kalbarri (~590 km)
