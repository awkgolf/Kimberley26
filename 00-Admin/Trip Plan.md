# Trip Plan

## Purpose

Record the planned August 2026 geological exploration from Perth north along the
Western Australian coast to Kalbarri.

## Route

Perth → Lancelin → Cervantes → Jurien Bay → Green Head → Kalbarri.

See [[Route]] for the itinerary and [[Safety and Permissions]] before fieldwork.

## Capture workflow

1. Create one [[../01-Journal/index|journal]] note per day.
2. Maintain one stable profile for each [[../02-Locations/index|location]].
3. Create one `OBS-NNN` note per outcrop or geological feature.
4. Create one `K26-NNN` note per sample.
5. Store media in `Attachments/` and describe it in [[../05-Photos/index|Photo Records]].
